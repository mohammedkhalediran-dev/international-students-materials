# Medixa — نسخة التصميم الجديد

المشروع الأصلي نفسه: HTML وCSS وJavaScript، مع Cloudflare Pages Functions وKV لرفع المحاضرات. لا يحتاج خطوة بناء جديدة، ومجلد النشر يبقى `site`.

## المعاينة قبل الرفع

افتح ملف `medixa-preview.html` المرفق في متصفح يدعم HTML وJavaScript. تتضمن المعاينة الصور والمحاضرات الموجودة، وبأعلى الصفحة اختيار الواجهة وحجم الحاسوب أو اللوحي أو الهاتف. الرفع والمساعد المتصل بالخادم غير مفعّلين في المعاينة؛ حفظ تقدم المعاينة مستقل عن الموقع الفعلي.

لإعادة توليد المعاينة من المصدر:

```bash
python3 scripts/make-preview.py medixa-preview.html
```

ويمكن تشغيل ملفات الموقع محلياً:

```bash
python3 -m http.server 8000 --directory site
```

ثم افتح `http://localhost:8000`. خدمة رفع المحاضرات تحتاج بيئة الخادم الموجودة في المشروع؛ الخادم الثابت يعرض التصميم والملفات المحلية فقط.

## ما تغيّر

- الرئيسية: صورة تشريحية جديدة، بطاقات الكورسات، متابعة آخر مادة، أحدث المحاضرات وأدوات الدراسة.
- قائمة جانبية فاتحة/داكنة، طي على الحاسوب ودرج وتنقل سفلي للهاتف.
- بطاقات أفقية: ثلاثة أعمدة على الشاشات الواسعة، عمودان على المتوسطة، وبطاقة واحدة في الصف على الهاتف.
- صفحات البحث والمحاضرات والمفضلة والمراجعة والأساتذة والإعدادات والمساعدة في `workspace.html?view=...`.
- مخطط دراسة: إضافة الجلسات وتعديلها وحذفها وإكمالها، عرض أسبوعي، مهام، مؤقت تركيز، عداد امتحان وتقدم القراءة.
- بنك تدريب يستخدم 27 سؤالاً من محتوى محاضرة المناعة الموجود أصلاً؛ يحفظ النتائج ويعرض الإجابات الخاطئة.
- ملاحظات مستقلة لكل ملف في قارئ PDF.
- اختيار الكورس الحالي واللغة والمظهر وتقليل الحركة وتنزيل نسخة من البيانات المحلية.
- إعادة تنسيق لوحة رفع المحاضرات مع الإبقاء على API والرموز والصلاحيات الحالية.
- تحديث العمل دون اتصال إلى `medixa-v30` واستثناء استجابات API من التخزين المؤقت.

بيانات المواد الـ37، ومنها مواد الكورس الثالث الـ14، وملفات PDF الأصلية ووظائف الرفع محفوظة. العربية والإنجليزية والفارسية مدعومة؛ الصياغة الفارسية الجديدة تحتاج مراجعة متحدث أصلي.

## الحسابات والدرجات

لا توجد في الملف الأصلي مصادقة للطلاب أو قاعدة درجات. تسجيل الدخول والملف الشخصي والدرجات الجامعية ما زالت غير مفعلة. تشغيلها يتطلب تحديد نظام الحسابات وربطه بالخادم ومصدر الدرجات والصلاحيات. مخطط الدراسة والتقدم والملاحظات والمفضلة والنتائج تُحفظ على الجهاز والمتصفح فقط، ولا تتزامن بين الأجهزة.

## تطبيق النسخة

1. احتفظ بنسخة من المشروع الحالي، ثم استبدل الملفات بمحتويات هذا الأرشيف مع إبقاء المجلدات في مواقعها.
2. احتفظ بإعداد نشر `site` وربط `LECTURES` وسر `UPLOAD_CODES` الحاليين. لا تضع الرموز في المستودع.
3. جرّب النسخة على فرع المعاينة الذي تستخدمه قبل اعتمادها للموقع الرئيسي.

لم تتضمن هذه المهمة رفعاً إلى GitHub أو نشراً على Cloudflare.

## التحقق

نجحت الفحوص التالية:

```bash
node tests/data_check.js
node tests/upload_api_check.mjs
node tests/kv_adapter_check.mjs
node tests/upload_names_check.js
node tests/redesign_check.mjs
```

جرى التحقق من صياغة JavaScript ووجود الموارد والروابط المحلية وبنك التدريب، وتضمين موارد المعاينة وصياغة برامجها، وبقاء بيانات المواد وملفات PDF والخادم الأصلية دون تغيير.

لم يتوفر تشغيل متصفح لهذه المهمة، لذلك لم تُختبر الواجهات بصرياً أو تفاعلاتها داخل متصفح. اختبارات Playwright القديمة تستهدف التخطيط السابق وبعض محدداتها تغيّر؛ لا تمثل نتيجة فحص النسخة الجديدة. عاين الهاتف والحاسوب والرفع الحقيقي على فرع التجربة قبل النشر النهائي.

تفاصيل الصورة وبرومبتها في `DESIGN-ASSETS.md`.
